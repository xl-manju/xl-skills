# Gate A サマリ — info-collector-agent

## 自然文サマリ（ユーザーの言葉に寄せて）

毎日 X タイムライン・arXiv・公式ブログ・クライアント会話URLから情報を漁っているが、本当にしんどいのは「収集→要約→アウトプット化」を毎回ゼロから回すことで、思考・企画・戦略設計に向ける時間が削られている状態。

そこでこのスキルは、既に運用している3つの収集スキル（arxiv-paper-reporter / x-post-reporter / ai-release-reporter）を**オーケストレータ**として束ね、その出力を**「自分の関心テーマ」で縦切りにキュレーション**する。テーマ集合は手動シードを起点に、Obsidian の過去ノートと過去 X 投稿から動的補強・週次チューニングする**ハイブリッド方式**で暗黙知を追随させる。

最終的に毎朝（cron 定刻＋オンデマンドの両対応で）、**Obsidian Vault に「本日の思考メモ」**を出現させ、Discord/Slack の固定チャンネルにサマリ通知をピン留めする。これは単なるニュース要約ではなく、「**複数ソースを自分の関心テーマで縦方向に下ろす**」キュレーションであり、毎朝そのメモをタネに今日の企画・戦略を書き始める**思考のスタートポイント**として機能させる。

派生のX長文・スライド・提案資料への展開はユーザー側または既存の専門スキル（x-longpost-creator / presentation-slide-generator 等）に委譲し、このスキル自体は思考メモの編集レイヤーに責務を集中する。

ナレッジ資産としては (a) 既存の Obsidian Vault・過去 X 投稿・講座資料を参照ソースに取り込み、(b) 暗黙知（過去アウトプットに現れる関心軸）を逆推定で抽出、(c) 必要に応じて外部記事・書籍も解析対象に加える。週次チューニングで関心テーマ集合を更新し続ける。

## 5軸サマリ表

| 軸 | 内容 |
|---|---|
| 出力先 | Obsidian Vault（思考メモ本体） + Discord/Slack（サマリ通知） |
| 情報源 | 既存3スキル（arxiv / x-post / ai-release-reporter）+ 会話URL貼り付け |
| 共有相手 | 自分（最優先）+ X フォロワー / クライアント・受講生 / チーム（派生用） |
| 真の課題 | 思考の延長としてのセカンドブレインを毎朝出現させ、企画・戦略の起点にする |
| ナレッジ資産 | Obsidian + 過去X投稿 + 講座資料 を参照、暗黙知抽出ハイブリッド、週次更新 |

## 責務境界（重要決定）

- **このスキルがやること**: テーマ縦切りキュレーション・思考メモ生成・配信
- **このスキルがやらないこと**: 個別ソース収集（既存スキルに委譲）／X長文・スライド・提案資料の最終整形（既存スキル or 手動）

## 設計選択（option-presenter で確定）

- O1: オーケストレータ型
- T3: テーマ抽出ハイブリッド（手動シード + 動的補強 + 週次チューニング）
- S3: 配信両対応（定刻 cron + オンデマンド）
