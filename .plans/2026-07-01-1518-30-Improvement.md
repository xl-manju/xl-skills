# skill-intake elegant-review 改善 — 計画と作業記録

作成: 2026-07-01 15:18 / 対象: `plugins/skill-intake/`（参照仕様 `plugins/skill-creator/`）

> 注: 当初の指定先 `.cc/` は既存の起動スクリプト（bash ファイル `.cc`）と競合するため、`.plans/` に保存。

## 背景・目的

- skill-intake を skill-creator 仕様へ準拠させ、Notion ヒアリングシートを「誰がやっても同一仕様」で再現性高く出力できる状態にする。
- 本質軸（ユーザー指示）: ユーザーは言語化できないので、手を差し伸べて「どういう入力をして・どういう出力をして欲しいか」を深掘り抽出する。これを決定論設計のアンカーに据える。

## 真因（Phase1-2 分析で確定、当初 4 条件すべて FAIL）

- 群α 三重正本 drift: 章の正本が section_canonical_map(12章) / section-completeness-rules(9章) / completeness-criteria(24項目) / check_completeness(実装は5軸のみ) に分裂。9章/24項目 doc は「check_completeness が検証する」と書くが未実装。
- 群β 決定論の射程不足（真因）: 決定論が「どの質問を出すか」で止まり、入力→出力インテント抽出（引き出し補助・回答正規化・章配置・公開）が固定化されていない。
- 群γ skill-creator 規範乖離: fidelity-guard の prefix、派生 rubric 継承の非明示、構造検証の Gate 帰属未定義。

## 完了済みの作業

### Phase3 改善（12 介入）
1. Intent Contract を第一級正本化（input_spec / output_spec / slot_status を新設 schema 化＝再現性アンカー）。
2. section_canonical_map §6 に intent_contract を必須追加、policy に派生宣言。
3. section-completeness-rules / completeness-criteria を「派生・非機械ガイド」と明示し、虚偽記述を修正。
4. Probe-Pattern-Table を新設（9 probe で全 intent slot をカバー、発火条件は決定論・文面 verbatim＝手を差し伸べるを決定論化）。
5. 回答→intent 正規化 script を新設（enum 写像で決定論マッピング、sha256 冪等）。
6. check_completeness に section / intent / all 検証を後方互換で追加、軸キー不一致を alias 解消。
7. intake.schema §6 に intent_contract 同期。
8. golden test を新設（同一入力 3 回で intent_contract の sha256 一致）。
9. fidelity-guard を assign-notion-fidelity-evaluator へ改名（di-quartet 準拠、39 参照＋symlink＋テスト追従、旧名参照 0 件）。
10. resource-map / plugin-composition に新リソースを登録し依存エッジを追加。
11. skill-creator 側の仕様補強（構造 fidelity の Gate 帰属、派生 plugin rubric 継承ルール）。
12. 未完だった軸キー rename を完了（cross_check 系テストを新キーへ整合）。

### 申し送り確認フェーズでの追加改善
- dead artifact リスクを検出し解消: quality_gate の完了ゲートに intent_contract 検証を接続。intent 未充足 slot で FAIL、旧 intake は migration_warn で後方互換。
