# 質問銀行（30問以上）

`scripts/update_question_bank.js`（self-updater agent）が反復毎に追記する自己進化辞書。
深度（quick/standard/deep）× 5軸（出力先/情報源/共有相手/真の課題/**ナレッジ資産**）の格子で参照する。
ナレッジ資産軸は **MUST**: 思考プロセス・考え方・外部情報をナレッジ化してスキルに注入する流れの有無を必ず確認する。

## 深度別ガイド

### quick（30秒〜1分・5問以内）

- 表層要望の確認のみ
- 5軸を1問ずつ計5問＋確認1問
- 例: Q02, Q09, Q16, Q23, Q32

### standard（5〜10分・10問程度）

- 5軸×2〜3問＋技法（5 Whys 1サイクル）
- 例: Q03, Q04, Q10, Q11, Q17, Q18, Q24, Q25, Q31

### deep（15〜30分・全問可）

- 5 Whys 完走＋Magic Wand＋Pain Story
- Reverse Brief で締める

## 自己進化ルール

- 1回のヒアリングで「ユーザー回答が想定パターンに当てはまらなかった質問」を抽出
- self-updater が **新質問の候補** として末尾に追加（草稿状態）
- 月次レビューで採用判断（人間レビュー必須）
- 最大エントリ数 200 を超えたら最低使用頻度から削除

## 使い方

```javascript
// agents/interviewer.md からの参照例
const bank = loadQuestionBank();
const next = bank.filter(q => q.axis === missingAxis && q.depth === currentDepth);
const picked = next[Math.floor(Math.random() * next.length)];
```
